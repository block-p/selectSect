# سنجش‌یار ۱۴۰۵ (SanjeshYar)

پلتفرم هوشمند، سبک و رایگان انتخاب رشته کنکور سراسری ۱۴۰۵ ایران بر اساس داده‌های رسمی سازمان سنجش آموزش کشور و انتشارات مهروماه و کانون.

## 🔗 لینک نسخه آنلاین
[مشاهده آنلاین سنجش‌یار](https://block-p.github.io/selectSect/)

## ⚡ ویژگی‌ها
- **۱۰۰٪ کلاینت‌ساید (Pure JavaScript):** بدون نیاز به سرور و دیتابیس، فوق‌العاده سریع (زیر ۵ میلی‌ثانیه).
- **دیتای واقعی ۱۴۰۵:** شامل بیش از ۴۰٬۰۰۰ کد رشته‌محل، ظرفیت‌ها، بومی‌گزینی (استانی، ناحیه‌ای، قطبی) و کف رتبه‌های قبولی.
- **چیدمان بهینه ۱۵۰تایی:** دسته‌بندی خودکار به انتخاب‌های رؤیایی (۳۰)، منطقی (۷۵) و کف قبولی تضمینی (۴۵).
- **دیزاین مینیمال:** طراحی مدرن و خلوت به سبک Emil Kowalski با پشتیبانی کامل از پرینت رسمی و خروجی اکسل (CSV).
